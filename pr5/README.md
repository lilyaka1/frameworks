# ПР5 — система учета API-интеграций на Django

В проекте реализованы требования предыдущих практик в Django-варианте:

- модели пользователей, сервисов, API, ключей, интеграций и API-запросов;
- добавление и поиск интеграций, сортировка по названию сервиса;
- безопасный статус ключа без вывода секрета;
- регистрация запросов, определение успешности и статистика;
- JSON-экспорт через `integrations.storage.export_data`;
- веб-страница `/` с поиском, интеграциями и статистикой;
- административная панель `/admin/` для работы с моделями;
- автоматические Django-тесты.

## Запуск

```bash
cd /Users/lilyaka/Desktop/раб.тетради/фреймворки/pr5
source .venv/bin/activate
python manage.py migrate
python manage.py seed_demo
python manage.py runserver
```

Для входа в админ-панель сначала создайте администратора:

```bash
python manage.py createsuperuser
```

Команду `seed_demo` можно запускать повторно: существующие демонстрационные
записи обновляются, дубли не создаются.
