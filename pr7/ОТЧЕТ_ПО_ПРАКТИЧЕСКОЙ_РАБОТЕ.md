# Отчёт по практической работе №7

**Проект:** «Система учёта API-интеграций»  
**Тема:** Деплой веб-приложения и настройка серверного окружения

## Выполненная работа

Для деплоя выбрана контейнерная инфраструктура Docker Compose. Образ собирается
на базе Python 3.13, зависимости устанавливаются из `requirements.txt`, а
приложение запускается через Gunicorn. Настройки `DJANGO_SECRET_KEY`,
`DJANGO_ALLOWED_HOSTS` и `DJANGO_DEBUG` передаются через переменные окружения.

В `docker-compose.yml` настроены публикация порта, автоматический перезапуск
контейнера и healthcheck адреса `/health/`. Перед запуском production
предусмотрены HTTPS через reverse proxy, ограничение hosts, резервное
копирование базы и хранение секретов вне репозитория.

## Команды деплоя

```bash
cp .env.example .env
# задать DJANGO_SECRET_KEY в .env
docker compose up --build -d
docker compose ps
curl http://localhost:8000/health/
```

Подготовлен воспроизводимый сценарий сборки и запуска приложения с проверкой
