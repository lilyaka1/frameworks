# Отчёт по практической работе №6

**Проект:** «Система учёта API-интеграций»  
**Тема:** Реализация backend- и frontend-логики

## Выполненная работа

Создано Django-приложение с моделями сервисов, API, интеграций, ключей,
пользователей и истории запросов. Реализованы REST-методы
`GET /api/integrations/`, защищённый `POST /api/requests/` и `GET /health/`.
Добавлены проверка связанных объектов, валидация HTTP-статуса и времени ответа,
CSRF, сессионная аутентификация, авторизация и кэширование GET-запроса.

Frontend выполнен на Django Templates, Bootstrap и JavaScript `fetch`.
Интеграции загружаются через REST API, данные выводятся безопасно через
`textContent`, секретные значения ключей не возвращаются.

Добавлены интеграционные тесты для API, авторизации и создания запроса.

## Вывод

Получено работающее клиент-серверное приложение с документированными
REST-маршрутами и базовыми механизмами безопасности.
