# Отчёт по практической работе №8

**Проект:** «Система учёта API-интеграций»  
**Тема:** Безопасность, мониторинг и надёжность деплоя

## Выполненная работа

В отдельной папке подготовлен production-вариант контейнерного запуска Django:
Gunicorn работает внутри Docker Compose, контейнер перезапускается при сбое,
а healthcheck регулярно проверяет `/health/`. Логи приложения выводятся в
stdout и доступны через `docker compose logs`.

Секретный ключ не хранится в исходном коде, production-режим выключает
debug, задаёт `ALLOWED_HOSTS` и включает secure cookie. Для внешнего сервера
предусмотрены HTTPS через reverse proxy, firewall с открытыми только нужными
портами и резервное копирование базы.

## Контроль работоспособности

```bash
docker compose up --build -d
docker compose ps
docker compose logs --tail=100 web
curl http://localhost:8000/health/
```

При дальнейшем росте нагрузки SQLite следует заменить PostgreSQL, кэш
вынести в Redis, а несколько экземпляров Gunicorn разместить за балансировщиком.

## Вывод

Реализованы практические меры мониторинга, защиты конфигурации и подготовки
приложения к отказоустойчивому масштабированию.
